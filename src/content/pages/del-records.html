The Monolithic Challenge

As one of the world's most influential independent Regional Mexican labels, DEL Records requires a digital infrastructure that can handle massive traffic spikes. However, their original website was built on a bloated AI builder, leading to failing PageSpeed scores, broken visual artifacts, and a manual process for updating artists and videos that wasted critical internal resources.

The Serverless Solution

We eliminated the builder completely. We hand-coded a flawless, semantic HTML5 structure powered by the Eleventy Static Site Generator. To remove human error entirely, we engineered custom data pipelines that bypass authentication walls to pull newest YouTube drops and scrape live Spotify listener data, injecting it directly into the site via GitHub Actions and Cloudflare deploy hooks.

Visual Hierarchy

Cinematic UI/UX

The original landing page was visually confusing with poor typography scaling and heavy red gradients that distracted from the artists. We overhauled the interface with enterprise-grade typography, subtle noise overlays, and strict visual hierarchy, ensuring fans immediately connect with the music and media.

Code Quality

Flawless HTML Semantics

The original builder left behind broken template artifacts, massive div bloat, and empty data voids. We ripped it all out, alongside writing a custom script to migrate decades of historical news content natively into Markdown. We replaced the entire ecosystem with a bulletproof, semantic HTML5 structure that achieves perfect accessibility scores.

Data Pipelines

Automated Spotify Listener Tracking

We engineered custom GitHub Actions that trigger a cron job every afternoon. The system pings the Spotify API, scrapes the fresh monthly listener data for every artist, updates their stats on the frontend, and automatically re-ranks the roster from largest to smallest. Zero human intervention required.

Automation Engineering

Dynamic Video Syncing

Instead of staff wasting time manually copying and pasting YouTube embed codes every week, our serverless build does it for them. Custom scripts fetch the latest drops directly from the label's channel during the build process, seamlessly injecting them into a high-performance, responsive grid.

Information Architecture

Dynamic Content Modules

We completely overhauled the label's static, unengaging text blocks. The new architecture processes company data into engaging, data-driven timelines and interactive historical roadmaps that load instantly across all devices.

Conditional Logic

Advanced Submission Routing

We designed structured, dynamic inquiry forms that adapt instantly based on user selection. Demo submissions require specific social and drive links, while press inquiries route differently, effectively streamlining the label's massive influx of internal A&R and booking communication.
